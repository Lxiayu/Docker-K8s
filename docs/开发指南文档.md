# 开发指南文档

## 1. 开发概述

### 1.1 项目架构
- **前端**：React 18 + TypeScript + Tailwind CSS + Vite
- **后端**：Go 1.21 + Gin + GORM + PostgreSQL
- **基础设施**：Docker + Kubernetes + Harbor + Prometheus + Grafana

### 1.2 开发环境要求
- **前端**：Node.js 16+，npm 7+
- **后端**：Go 1.21+，PostgreSQL 15+
- **基础设施**：Docker，Kubernetes (kind/minikube)

### 1.3 开发工具推荐
- **IDE**：VS Code，Goland
- **版本控制**：Git
- **容器管理**：Docker Desktop
- **Kubernetes管理**：kubectl，k9s
- **数据库管理**：pgAdmin，DBeaver

## 2. 前端开发指南

### 2.1 项目结构
```
frontend/
├── src/
│   ├── components/       # 组件
│   │   ├── charts/       # 图表组件
│   │   └── ui/           # UI组件
│   ├── lib/              # 工具库
│   ├── pages/            # 页面
│   ├── services/         # API服务
│   ├── store/            # 状态管理
│   ├── styles/           # 样式
│   ├── utils/            # 工具函数
│   ├── App.tsx           # 应用入口
│   └── main.tsx          # 主入口
├── public/               # 静态资源
├── package.json          # 依赖配置
├── tsconfig.json         # TypeScript配置
└── vite.config.ts        # Vite配置
```

### 2.2 开发流程
1. **安装依赖**：`npm install`
2. **启动开发服务器**：`npm run dev`
3. **代码检查**：`npm run lint`
4. **构建**：`npm run build`
5. **预览**：`npm run preview`

### 2.3 代码规范
- **命名规范**：
  - 组件名：大驼峰命名法（如 `Dashboard.tsx`）
  - 变量名：小驼峰命名法（如 `userName`）
  - 常量名：全大写加下划线（如 `API_URL`）
- **代码风格**：
  - 使用 TypeScript 类型定义
  - 使用 ES6+ 语法
  - 组件使用函数式组件和 Hooks
  - 使用 Tailwind CSS 进行样式管理

### 2.4 状态管理
- 使用 Zustand 进行状态管理
- 状态分为全局状态和局部状态
- 全局状态包括：用户认证、主题设置等
- 局部状态使用 React useState Hook

### 2.5 API 调用
- 使用 Axios 进行 HTTP 请求
- 使用 React Query 进行数据管理
- API 服务统一放在 `services` 目录
- 实现错误处理和重试机制

### 2.6 组件开发
- 组件设计遵循单一职责原则
- 组件分为展示型组件和容器型组件
- 使用 Radix UI 作为基础组件库
- 自定义组件放在 `components` 目录

### 2.7 路由管理
- 使用 React Router 6 进行路由管理
- 路由配置在 `App.tsx` 中定义
- 实现路由守卫，确保只有登录用户才能访问受保护的路由

## 3. 后端开发指南

### 3.1 项目结构
```
backend/
├── cmd/                 # 应用入口
│   ├── genhash/         # 密码哈希生成工具
│   ├── seed/            # 数据种子工具
│   └── server/          # 服务器入口
├── internal/            # 业务代码
│   ├── handlers/        # 请求处理器
│   ├── middleware/      # 中间件
│   ├── models/          # 数据模型
│   ├── router/          # 路由配置
│   ├── seed/            # 种子数据
│   ├── seeder/          # 数据填充器
│   └── services/        # 业务逻辑
├── pkg/                 # 公共库
│   ├── config/          # 配置管理
│   ├── database/        # 数据库连接
│   ├── errors/          # 错误处理
│   ├── logger/          # 日志管理
│   └── response/        # 响应处理
├── configs/             # 配置文件
├── go.mod               # 依赖管理
└── Makefile             # 构建脚本
```

### 3.2 开发流程
1. **安装依赖**：`go mod tidy`
2. **运行开发服务器**：`make run`
3. **运行测试**：`make test`
4. **构建**：`make build`
5. **生成密码哈希**：`go run cmd/genhash/main.go`
6. **填充测试数据**：`go run cmd/seed/main.go`

### 3.3 代码规范
- **命名规范**：
  - 包名：小写字母，使用简短的单字
  - 函数名：大驼峰命名法（如 `LoginHandler`）
  - 变量名：小驼峰命名法（如 `userName`）
  - 常量名：全大写加下划线（如 `API_PORT`）
- **代码风格**：
  - 使用 Go 1.21+ 语法
  - 遵循 Go 官方代码规范
  - 使用 `gofmt` 格式化代码
  - 函数长度控制在 50 行以内

### 3.4 API 设计
- **RESTful API**：遵循 RESTful 设计原则
- **API 版本**：使用 `/api/v1` 前缀
- **请求方法**：使用 GET、POST、PUT、DELETE 等 HTTP 方法
- **响应格式**：统一的 JSON 响应格式
- **错误处理**：统一的错误响应格式

### 3.5 数据库操作
- 使用 GORM 进行数据库操作
- 数据模型定义在 `models` 目录
- 数据库迁移使用 GORM 的自动迁移功能
- 事务处理：重要操作使用数据库事务

### 3.6 中间件
- **认证中间件**：JWT 认证
- **CORS 中间件**：跨域资源共享
- **日志中间件**：请求日志记录
- **恢复中间件**：异常捕获和恢复

### 3.7 配置管理
- 使用 Viper 进行配置管理
- 配置文件放在 `configs` 目录
- 支持环境变量覆盖配置
- 配置结构定义在 `pkg/config` 目录

### 3.8 日志管理
- 使用 Zap 进行日志管理
- 日志级别：debug、info、warn、error
- 日志输出：控制台和文件
- 日志格式：JSON 格式

## 4. 数据库开发指南

### 4.1 数据库结构
- **用户表**：存储用户信息
- **仓库表**：存储代码仓库信息
- **流水线表**：存储流水线配置和状态
- **部署表**：存储部署信息和状态
- **镜像表**：存储镜像信息
- **监控表**：存储监控数据
- **设置表**：存储系统设置

### 4.2 数据库迁移
- 使用 GORM 的自动迁移功能
- 迁移文件放在 `internal/models` 目录
- 每次修改数据模型后自动迁移

### 4.3 数据库备份
- 定期备份数据库
- 备份脚本放在 `database/scripts` 目录
- 支持全量备份和增量备份

### 4.4 数据库性能优化
- **索引**：为常用查询字段添加索引
- **查询优化**：使用合适的查询语句，避免全表扫描
- **连接池**：配置合理的数据库连接池
- **分区**：对大表进行分区管理

## 7. 安全开发指南

- **API 限流**：防止 API 滥用

### 7.3 安全扫描
